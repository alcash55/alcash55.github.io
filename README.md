# alcash55.github.io

A one-page redirect to the live portfolio at
https://portfolio-website.alex-e-cash28.workers.dev/.

LinkedIn's link preview cannot connect to `workers.dev`, which serves only an
ECDSA certificate. GitHub Pages serves RSA, so LinkedIn can read this page's
preview tags (title, description, image). People who open the link go straight
on to the portfolio. The image lives here because the preview fetches it from
the page's own host.

The archived v1 site at https://alcash55.github.io/Portfolio/ is a separate
project site and is not affected.
